Geometry Nodes Along a Curve

A rail handcar has a chain loop, and it runs on a railway track. Both are Geometry Nodes sitting on a curve, yet the two node trees look nothing alike. One question explains the difference: does the part stay rigid, or does it have to bend? This page shows both trees and every node in them — what it does, why it is there, and when to use it.

Part 1

The idea

Decide this before adding a single node.

Rigid or bending

Ask what the part does on a turn. The answer picks the method, and the method is why the two trees look different.

Rigid → copy it

Place copies of the piece

A chain link, a sleeper, a fence post: it keeps its shape. For every copy the tree only answers two questions — where does it go, and which way does it face. That is Curve to Points followed by Instance on Points.

Used for: chain links, sleepers.

Bending → move its vertices

Build it straight, then bend it

A rail, a pipe, a cable: it must stay one unbroken piece through the turn. Copies of a straight piece cannot do that — on a 6 m test turn they left 84 cm of gaps in the outer rail. So the tree builds a straight strip and moves every vertex onto the curve with Set Position.

Used for: rails.

Chain, sleepers, rails side by side

The sleeper branch is the chain method with a single piece. That is why one part of the track tree looks like the chain tree, and the rail part looks like nothing else.

Which way is up

A copy needs a full orientation: the direction along the curve (the tangent) and a second direction that stops it rolling.

The chain loop stands upright. The rotation that Curve to Points gives each point is steady around a loop in one plane, so the chain tree uses it directly. One fixed Rotate Rotation then turns the link model to lie along the chain. The angle depends on how the link was modelled and how the path sits — in your file it is Y 90°, Global.

The track lies on the ground. There, "up" is simply +Z. The curve's own normal on RailPath does not point up — rails built with it landed 60 cm off the path — and on slopes it rolls a little as it follows the curve. So both track branches build their rotation from the tangent plus a fixed up of (0, 0, 1). Because sleepers and rails use the same rule, they stay lined up: the rails sit on the sleeper plates within 7 mm.

Rule of thumbA loop that stands up — chain, conveyor belt, tank track: use the curve's rotation. Anything lying on the ground — rails, road, fence: use the tangent plus world up.

Part 2

The trees

Drawn the way they look in Blender's node editor. Solid wires carry geometry or single values; dashed wires carry a field — a value for every point or vertex.

The chain tree

Geometry Nodes modifier on ChainPath. Eight nodes. Read it left to right.

inputgeometryconvertervectorgroup in / out geometry or valuefield
  1. Group Input hands over the curve itself — the modifier sits on ChainPath.
  2. Curve to Points puts 170 evenly spaced points around the loop. Each point carries a rotation that follows the curve.
  3. Two Object Info nodes read the two link meshes. Geometry to Instance turns them into a list of two.
  4. Instance on Points with Pick Instance places link 1, link 2, link 1, link 2… on the points.
  5. Rotate Rotation adds a fixed 90° so each link lies along the chain instead of across it.
  6. Group Output shows the links instead of the curve line.

The track tree

Geometry Nodes modifier on RailPath. 22 nodes, easier to read as three groups — build and check them in this order. Grey dashed boxes stand for a node shown in another group.

Group 1

Sleepers — the chain method with one piece

  1. Curve to Points in Length mode gives a point about every 55 cm, plus the tangent there.
  2. Axes to Rotation makes a rotation whose X follows the tangent and whose Z points up.
  3. Instance on Points puts one sleeper on each point, turned that way.
Group 2

A straight rail strip

  1. Curve Length ÷ 0.4229, then Floor = how many whole rail pieces fit. 47 on your 19.9 m path.
  2. Mesh Line makes that many points in a straight line along X, one rail piece apart.
  3. Instance on Points puts a rail piece on each; Realize Instances turns them into one real mesh so its vertices can be moved.
Group 3

Bend the strip onto the curve

  1. For every vertex of the straight strip, X is how far along the track it is; Y and Z are how far to the side and how high.
  2. Sample Curve turns X into a point on the curve and the direction there.
  3. Combine XYZ rebuilds the side-and-height offset (0, Y, Z); Axes to Rotation and Rotate Vector turn that offset to face along the track.
  4. Vector Math adds the point and the turned offset. Set Position moves the vertex there.
  5. Join Geometry adds the sleepers from group 1, and Group Output shows both.

Wide trees scroll sideways inside their box.

Part 3

Build it yourself

Add nodes with Shift+A and type the name. Drag from an output dot to an input dot to wire them. Check the result after every step before moving on.

Build the chain

Two link types alternating around a closed curve, pins sitting in the holes.

Before the nodes

Get the pieces ready

  • Each link object has its origin in the middle of the link: Object → Set Origin → Origin to Geometry.
  • Delete any Array or Curve modifier on the links — even a disabled one that points at the path makes a dependency loop.
  • Hide the link objects (H). The tree still reads them.
  • On the path: Object Data → Shape → Resolution Preview U 32. At 12 the pins missed the holes by up to 1.7 mm.

Nodes

Wire it up

  1. Select the path → Modifiers → Add Modifier → Geometry Nodes → New.
  2. Curve to Points: Group Input Geometry → Curve. Mode Count. Count = path length ÷ pin spacing, rounded to an even number (2430 mm ÷ 14.37 mm → 170).
  3. Two Object Info nodes, one per link → both into one Geometry to Instance.
  4. Instance on Points: Points ← Curve to Points; Instance ← Geometry to Instance; tick Pick Instance.
  5. Rotate Rotation: Curve to Points Rotation → Rotation; Rotate By 90° on one axis → Instance on Points Rotation. Try X, Y and Z until the links stand like a chain.
  6. Instance on Points → Group Output.

CheckLinks alternate, and on the sprockets the pins still sit in the holes.

Build the track

Sleepers placed, rails bent — in one tree on the path. Each group ends with something you can see, so a mistake shows up right away.

Before the nodes

Get the pieces ready

  • Split the track tile into two objects: the rail (with loop cuts along it, so it has vertices to bend) and the sleeper with its plates and bolts. Keep only Mirror on them, and hide both.
  • Model both with the track running along X, Y sideways and Z up. Centre the sleeper on its origin.
  • Units: this file measures length in centimetres. In a length field type 42.29, not 0.4229. Math nodes have no units.

Group 1

Sleepers

  1. Group Input Geometry → Curve to Points. Mode Length, Length 55 cm.
  2. Object Info (the sleeper) → Instance of an Instance on Points; Points ← Curve to Points.
  3. Axes to Rotation, set to Primary X, Secondary Z: Tangent → Primary Axis; type 0, 0, 1 in Secondary Axis; Rotation → Instance on Points Rotation.
  4. Instance on Points → Group Output (for now).

CheckSleepers along the path, square to it.

Group 2

A straight rail strip

  1. Curve Length (Curve ← Group Input) → Math Divide by 0.4229 → Math Floor → Count of a Mesh Line.
  2. Mesh Line: mode Offset, Start Location X 21 cm, Offset X 42.29 cm.
  3. Mesh Line → Points of a second Instance on Points; Instance ← Object Info (the rail) → Realize Instances → Set Position.
  4. Join Geometry with Set Position and the sleepers' Instance on Points → Group Output.

CheckSleepers on the path, and the rails in one straight line along X.

Group 3

Bend the strip

  1. Position → Separate XYZ.
  2. Sample Curve, Mode Length: Curves ← Group Input; Length ← Separate X.
  3. Combine XYZ: Y ← Separate Y, Z ← Separate Z. X stays 0.
  4. Vector Math (Add): Sample Curve Position + Combine XYZ → Set Position Position.

CheckThe rails follow the path but squeeze together on the turn. That is expected.

  1. Rotate Vector between Combine XYZ and Vector Math.
  2. A second Axes to Rotation (X / Z, Secondary 0, 0, 1): Sample Curve Tangent → Primary; Rotation → Rotate Vector Rotation.

CheckThe rails stay parallel — 1.50 m apart along the whole path.

Why the line starts at 21 cm: the rail mesh reaches 20.5 cm behind its origin. Starting at 0 would put that part before the start of the curve, where Sample Curve piles every vertex onto the first point.

Part 4

Look it up

Every node in both trees, and how the same idea is built in Unreal.

Node by node

In the order you meet them. The tags show which part uses each node.

Group Input

Groupchaintrack
What it does
Hands over the geometry of the object the modifier sits on — here, the curve itself.
Why here
Everything starts from the path: points along it, its length, positions on it.
Use it when
Always. One output can feed as many inputs as need the curve.
In your file
ChainPath: into Curve to Points. RailPath: into Curve to Points, Curve Length, and Sample Curve through a Reroute.
Watch out
If the modifier's monitor icon is off, nothing from the tree shows in the viewport.

Object Info

Inputchainsleepersrails
What it does
Reads another object's geometry, with its modifiers, into this tree.
Why here
The links, the sleeper and the rail piece are ordinary objects you model and edit; the tree borrows them.
Use it when
You want to place or bend a mesh that lives in its own object.
In your file
Original. ChainLink1, ChainLink2, SM_Reils_Rail, SM_Reils_Sleeper (As Instance on — it works either way here).
Watch out
Original uses the mesh around its own origin, wherever the object sits — so the origin must be in the right place. A link whose origin was 3.4 m away flew off the chain. Modifiers on the source still count: an Array or Curve modifier pointing at the same path makes a dependency loop, even when disabled.

Curve to Points

Geometry · curvechainsleepers
What it does
Puts points along a curve. Each point also carries the curve's Tangent, Normal and a ready-made Rotation.
Why here
The points are the spots where copies go.
Use it when
Copies spaced along a path. Count for an exact number, Length for a spacing.
In your file
Chain: Count 170. Sleepers: Length 55 cm.
Watch out
On a closed loop, Count spreads the points evenly with no double point at the join — make it even when two pieces alternate. Length puts a point at both ends and evens out the rest, so 55 cm became about 54 cm on your 19.9 m path.

Geometry to Instance

Geometry · instanceschain
What it does
Turns each geometry wired into it into one instance of a list, in the order of the wires.
Why here
Pick Instance needs a list to pick from: link 1 and link 2.
Use it when
Two or more different pieces take turns, or you pick one at random.
In your file
Two wires: ChainLink1 and ChainLink2.
Watch out
Without Pick Instance ticked, Instance on Points places the whole list on every point.

Instance on Points

Geometry · instanceschainsleepersrails
What it does
Puts a copy of the Instance geometry on every point, turned by Rotation and sized by Scale.
Why here
Chain links and sleepers are rigid copies. In the rail branch it lines the rail pieces up before they are bent.
Use it when
Many copies of the same rigid thing. Copies are light: they all share one mesh.
In your file
Chain: Pick Instance on. Sleepers: Rotation from Axes to Rotation. Rails: no rotation, the strip is straight along X.
Watch out
Copies never bend. Pick Instance chooses by the point's index and wraps round: 2 pieces on 170 points gives 1, 2, 1, 2…

Rotate Rotation

Converter · rotationchain
What it does
Adds a fixed turn to a rotation. Global turns around the object's axes; Local around the copy's own axes.
Why here
The rotation from Curve to Points does not match the way the link was modelled, by a fixed 90°.
Use it when
You use the curve's rotation and the model faces wrong by the same amount everywhere.
In your file
Global, Y 90°.
Watch out
The right axis depends on the model and on how the path sits. After you rotate the path it can change — try 90° on X, Y and Z and look.

Axes to Rotation

Converter · rotationsleepersrails
What it does
Builds a rotation from two directions. The primary axis follows its direction exactly; the secondary stays as close to its direction as it can while staying at a right angle to the first.
Why here
"X along the track, Z up" is exactly how sleepers and rails should face.
Use it when
You know a direction along something (a tangent) and roughly where up is.
In your file
Primary Axis X ← Tangent; Secondary Axis Z = (0, 0, 1). One for the sleepers, one for the rail bend.
Watch out
It starts as Primary Z / Secondary X — change both dropdowns. The curve's Normal as "up" put the rails 60 cm off.

Curve Length

Geometry · curverails
What it does
The total length of the curve, as one number.
Why here
To work out how many rail pieces fit.
In your file
Curve ← Group Input: 19.9 m.
Watch out
The number is in metres even when your fields show centimetres, so the divide after it uses 0.4229.

Math

Converterrails
What it does
Arithmetic on single numbers — here Divide, then Floor.
Why here
Length ÷ piece length = how many pieces. Floor drops the fraction, so only whole pieces are made and the strip never runs past the end of the curve.
Use it when
Any count, ratio or rounding.
In your file
Divide by 0.4229, Floor → 47.
Watch out
Math fields have no units: 0.4229 here, but 42.29 in a centimetre field.

Mesh Line

Geometry · meshrails
What it does
A row of points: Count of them, starting at Start Location, each Offset from the last.
Why here
It is the straight "array" the rail pieces sit on, one piece length apart.
Use it when
You need evenly spaced points on a straight line.
In your file
Offset mode. Start Location X 21 cm, Offset X 42.29 cm, Count from Floor.
Watch out
Typing 0.4229 into the centimetre field made 0.42 cm and stacked all 47 pieces in one spot.

Realize Instances

Geometry · instancesrails
What it does
Turns instances into real geometry.
Why here
Set Position must move each vertex of the rail. On instances it would only move whole copies.
Use it when
Before changing the vertices of something that was instanced.
Watch out
Real geometry is heavier than instances. Realize only what has to bend — the sleepers stay instances.

Position

Input · attributerails
What it does
The position of each element being worked on — here every vertex of the rail strip. It is a field: a different value for every vertex.
Why here
A vertex's place in the straight strip says where it belongs on the curve.
Watch out
Field wires are drawn dashed. That is normal, not an error.

Separate XYZ

Converter · vectorrails
What it does
Splits a vector into its X, Y and Z numbers.
Why here
X means distance along the track; Y and Z mean sideways and height. They are used differently.
Watch out
Wire X into Sample Curve Length. Y there sends every vertex to the wrong spot.

Sample Curve

Geometry · curverails
What it does
Reads the curve at a distance (Length mode) or a fraction (Factor mode) and gives the Position, Tangent and Normal there.
Why here
Turns each vertex's X into its point and direction on the path.
Use it when
You need "the point this far along the curve".
In your file
Length mode. Curves ← Group Input, Length ← Separate XYZ X.
Watch out
A length before the start or past the end sticks to the first or last point — checked: −1 m lands exactly on the start. That squashes geometry, which is why the strip uses whole pieces and starts at 21 cm.

Combine XYZ

Converter · vectorrails
What it does
Builds a vector from three numbers.
Why here
Rebuilds the side-and-height offset (0, Y, Z).
Watch out
X stays 0 — it was already used as the distance along the curve. Adding it again would push the rail forward.

Rotate Vector

Converter · rotationrails
What it does
Turns a vector by a rotation.
Why here
The offset (0, Y, Z) points along world axes. On a turn it has to turn with the track, or the two rails squeeze together — they came within 6 cm.
In your file
Vector ← Combine XYZ, Rotation ← the rail's Axes to Rotation.

Vector Math

Vectorrails
What it does
Maths on vectors. Add is the default.
Why here
New position = point on the curve + turned offset.
In your file
Add: Sample Curve Position + Rotate Vector.

Set Position

Geometryrails
What it does
Moves points or vertices. Position replaces each one; Offset adds to it.
Why here
This is the bend itself: every vertex of the straight strip goes to its place on the curve.
Use it when
You deform geometry with a formula.
In your file
Geometry ← Realize Instances, Position ← Vector Math.
Watch out
Use Position, not Offset: the value is already the full new position.

Join Geometry

Geometrytrack
What it does
Combines several geometries into one.
Why here
Group Output takes one geometry, and the track is rails plus sleepers.
Watch out
Each part stays as it was: the sleepers stay instances, the rails stay a mesh.

Group Output

Groupchaintrack
What it does
Whatever reaches it replaces the object's own geometry in the viewport and the render.
Why here
The chain or the track should show, not the curve line.
Watch out
A branch that is not wired through to it shows nothing, however correct it is.

Reroute

Layouttrack
What it does
A dot on a wire that only tidies the layout. It changes nothing.
In your file
Between Group Input and Sample Curve's Curves.
